# Road Lane Detection

## Project Overview
This project aims to detect road lane markings using Python and OpenCV as part of an Image Processing course.

## Objectives
- Detect solid and dashed lane markings.
- Apply image processing techniques to road images.
- Investigate the detection of road defects and unexpected objects.
- Explore possible applications to airport runway markings.

## Technologies
- Python
- OpenCV
- NumPy

## Planned Methodology
1. Collect sample road images.
2. Convert images to grayscale.
3. Apply Gaussian blur for noise reduction.
4. Use Canny edge detection.
5. Select a region of interest.
6. Apply Hough Line Transform to detect lane markings.
7. Evaluate results and improve detection of dashed lines.

## Project Status
In development. Implementation and test results will be added progressively.
